## Intent

한글날(2026-10-09 금, 제580돌) 프로모션 모션그래픽. 레퍼런스 두 캠페인을 섞는다.
A는 노랑·검정 그런지 키네틱 타이포(추석 캠페인, `references/ref-01..06`), B는 레진절의 전통 궁궐과 빨강·파랑·금(`references/ref-07..10`).
흐름은 B 전통 인트로(어둠) → A 노랑 그런지 본론 → B 파랑 엔딩. 천지인(· ㅡ ㅣ)을 반복 전환 장치로 쓰고, 혜택 3개는 가·나·다 삼행시로 보여준다.

길이 40초 (사용자, 2026-09-28): 90초가 길어서 줄인 것이다. 구성(장면 7개)은 줄이지 않고 40초 동안 꽉 찬 모션으로 보여준다.
최종 아웃풋은 HTML 컴포지션으로 전달해도 된다 (사용자).

## Notes

- 폰트는 Pretendard 하나 (제목 Black, 카피 Bold, 라벨 SemiBold). 디자인 프리셋에는 한글 폰트가 없으므로 한글은 반드시 Pretendard로 렌더한다 (시스템 폰트 대체 금지).
- 자동 파이프라인을 고를 때 "프리셋 적용으로 폰트·색이 레퍼런스와 달라질 수 있음"을 사용자에게 알렸다 (2026-09-28).
- 엔딩 로고는 레진만. 워터마크 없음. 봄툰 작품 캐릭터가 들어가면 레진 서비스 여부를 사용자가 확인하기로 함.
- 화면에 작품명 표기 안 함. 작품 선정과 이미지 사용 권리는 사용자·사내 확인 사항.
- 제외: 레퍼런스 7번 무대(연기·조명은 3D 소스 필요), 옛한글, 한자 선행 표기.
- `CLAUDE.md`의 "Motion studio rules" 적용.
- 캐릭터 AI 재생성 (사용자 결정, 2026-09-28): 웹 원화 컷아웃이 원화 틀에 잘려 네모로 보여서, Codex 이미지 생성으로 전신 컷아웃을 다시 만든다. 작가 동의·계약 범위 확인이 필요하다고 안내했고 사용자가 재생성을 선택함. 공개 전 사내 확인 필요. 웹 컷아웃은 `assets/characters/web/`에 예비로 보관.
- 코드로 표현하기 어려운 요소(궁궐·한옥, 매듭, 엽전, 붓터치)는 레이아웃 칸 비율에 맞춰 이미지로 생성(`assets/props/`). 코드 트랜지션에 유리한 요소(천지인 획, 막대, '극'의 ㅡ 늘어남)는 SVG/코드로 만든다.
